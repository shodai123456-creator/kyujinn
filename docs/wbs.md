## 実装順序と依存関係

`M1 → M2/M3 → M4 → M5 → M6 → M7 → M8`

M2とM3は基盤完成後に並行可能。M6の求人ソース調査は実装と並行して継続し、規約確認が終わったコネクタだけを追加する。

## PM運用

- 各マイルストーン開始時に受入条件とリスクを確認する
- 仕様変更は要件ID、理由、影響範囲を記録する
- コネクタ規約は定期再確認し、変更時は審査完了まで停止する
- 推薦精度は総合点ではなく「上位求人を本人が保存した割合」でも評価する
- MVP完成を優先し、自動応募や生成AI機能は追加しない
